# Poster images (auth background wall)

Sixteen portrait crops (360 x 540 JPEG, about 600 KB in total) used by the `PosterWall` background of
the sign-in / sign-up screens. They are bundled so the screens look the same offline and before
sign-in (no API call needed).

Source: [Unsplash](https://unsplash.com). Licence: [Unsplash License](https://unsplash.com/license)
(free to use, no permission or attribution required; attribution is given here anyway). The photos
are the same ones used by the seed catalogue (`server/prisma/seed-data/media.ts`); the photographer
of each photo is credited on its Unsplash page `https://unsplash.com/photos/<photo id>`.
