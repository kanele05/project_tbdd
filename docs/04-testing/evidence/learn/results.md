# Kết quả kiểm thử — nhóm chức năng Học tập, Q&A, Project, Giảng viên, AI (area `learn`)

Môi trường: bản build web (cùng mã nguồn production) tại http://localhost:8090, API http://localhost:4000/api/v1, PostgreSQL cục bộ, trình duyệt Microsoft Edge (Playwright, headless). Tài khoản: học viên mẫu `martha.rosie@example.com`. Phone = 390×844 (vi, sáng), Desktop = 1440×900 (vi, tối). Ảnh nằm cùng thư mục với file này. AI dùng Google Gemini thật (free tier, tối đa ~5 lần gọi thật, kết quả được cache DB); các trạng thái lỗi/loading của AI không tái hiện được bằng Gemini thật nên được mô phỏng bằng cách chặn mạng trình duyệt (ghi rõ trong cột Kết quả thực tế).
